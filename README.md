# lil view

Быстрый просмотрщик изображений для macOS. Открываешь одну картинку — листаешь всю папку.

Часть набора **lil** — небольшие локальные инструменты, которые делают что-то одно:

| | |
|---|---|
| **lil view** | смотреть — вы здесь |
| [lil edit](https://github.com/mitya-lsnk/lil-edit) | переделывать: сжатие, удаление фона, апскейл |

Оформление общее: те же четыре скина и та же светлая/тёмная тема.

## Что умеет

- Листание всей папки стрелками и колесом, зум, поворот, полный экран.
- Плёнка миниатюр и сетка на всю папку.
- Слайдшоу и панель EXIF.
- HEIC, TIFF, PSD и камерные RAW — через системный ImageIO, без сторонних декодеров.
- **Одна кнопка**, которая делает lil view приложением по умолчанию для всех типов
  изображений сразу.

## Как это устроено

```
src/                  React + TypeScript
  theme.css           семантические токены (общие с lil edit)
  skins.css           studio / brutal / riso / device
  dark.css            тёмная тема для каждого скина
  viewer.css          раскладка просмотрщика
  components/Stage    зум и панорамирование одним transform
src-tauri/src/
  proto.rs            протокол limg:// — байты идут мимо IPC
  imageio.rs          мост к ImageIO (декод, кодирование, метаданные)
  assoc.rs            ассоциации файлов через LaunchServices
  scan.rs             список папки и натуральная сортировка
  fileops.rs          Корзина, перемещение, буфер обмена, конвертация
```

Два решения, которые стоит знать, прежде чем что-то менять:

**Байты изображений не ходят через IPC.** Tauri сериализует `Vec<u8>` в JSON-массив
чисел — для 40-мегабайтной фотографии это десятки мегабайт текста. Вместо этого
зарегистрирован свой URI-протокол `limg://`, и `<img src>` тянет данные так же, как
любой другой ресурс. Форматы, которые WebKit читает сам, отдаются файлом как есть.

**Ассоциации перечитываются после записи.** LaunchServices возвращает успех и на вызов,
который система потом игнорирует, поэтому `assoc.rs` после установки опрашивает каждый
тип заново и показывает результат построчно.

## Сборка

```bash
npm install
npm run tauri dev      # разработка
npm run tauri build -- --bundles app
```

Чтобы ассоциации закреплялись, приложение должно лежать в `/Applications`: macOS
привязывает обработчик к конкретной копии бандла.

## Требования

macOS 12+, Node 20+, Rust (stable).
