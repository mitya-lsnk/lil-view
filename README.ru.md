# lil view

[English](README.md) · **Русский**

Быстрый просмотрщик изображений для macOS. Открываешь одну картинку — листаешь всю
папку. HEIC, TIFF, PSD и камерные RAW читаются системным ImageIO, поэтому сторонних
декодеров внутри нет, а из машины ничего не уходит: приложение вообще не открывает
сетевых соединений. См. [Что уходит в сеть](#что-уходит-в-сеть).

Часть набора **lil** — небольшие локальные инструменты, каждый делает что-то одно:

| | |
|---|---|
| [lil edit](https://github.com/mitya-lsnk/lil-edit) | переделывать: сжатие, удаление фона, апскейл |
| **lil view** | смотреть: быстрый просмотрщик для macOS — вы здесь |
| [lil download](https://github.com/mitya-lsnk/lil-download) | приносить: видео и звук отовсюду, куда дотягивается yt-dlp |

## Установка

Готовые сборки — во [вкладке Releases](../../releases), либо соберите сами (ниже).

Подписи нет: первый запуск — правой кнопкой по приложению, «Открыть». Прежде чем
назначать ассоциации файлов, положите его в `/Applications`: macOS привязывает
обработчик к конкретной копии бандла, и приложение, запущенное из `~/Downloads`,
потеряет ассоциацию, как только переедет.

## Два решения, которые стоит знать

**Байты изображений не ходят через IPC.** Tauri сериализует `Vec<u8>` в JSON-массив
чисел — для сорокамегабайтной фотографии это десятки мегабайт текста на каждое
открытие. Вместо этого зарегистрирован свой URI-протокол `limg://`, и `<img src>`
тянет данные так же, как любой другой ресурс. Форматы, которые WebKit читает сам,
отдаются файлом как есть.

**Ассоциации перечитываются после записи.** LaunchServices возвращает успех и на
вызов, который система потом игнорирует. Поэтому [`assoc.rs`](src-tauri/src/assoc.rs)
после установки опрашивает каждый тип заново и показывает результат построчно, а не
объявляет победу, которую не может проверить.

## Язык интерфейса

Интерфейс есть на **русском и английском**, переключается в шапке. Весь текст лежит в
[`src/lib/strings.tsx`](src/lib/strings.tsx) — добавьте ключ в объект `RU`, и
компилятор потребует парный `EN`, так что забытый перевод будет ошибкой сборки, а не
пустой подписью.

## Стек

- **Tauri 2** — каркас (Rust-бэкенд + системный WebView). Лёгкий, ~10 МБ рантайма.
- **React + TypeScript + Vite** — фронтенд.
- **ImageIO** — системный декодер через тонкий мост на Rust. Всё, что открывает macOS,
  открывает и lil view, без единого вшитого кодека.

---

## Сборка

Нужны macOS 12+, Node ≥ 20 и Rust.

```bash
npm install          # один раз
npm run tauri dev    # разработка
```

Собрать релизный `.app`:

```bash
npm run tauri build -- --bundles app
```

---

## Что уходит в сеть

**Ничего.** Ни проверки обновлений, ни телеметрии, ни аналитики, ни отчётов о
падениях, ни аккаунта. Своих соединений приложение не открывает вовсе — единственный
трафик, который оно может вызвать, это ссылка, по которой вы кликнули, и открывается
она в браузере, а не в приложении.

## Как это устроено

```
lil-view/
├── src/                        # фронтенд (React)
│   ├── theme.css               # семантические токены (общие со всем набором lil)
│   ├── skins.css               # studio / brutal / riso / device
│   ├── dark.css                # тёмная тема для каждого скина
│   ├── viewer.css              # раскладка просмотрщика
│   ├── lib/
│   │   ├── limg.ts             # мост к протоколу limg://
│   │   ├── folder.ts           # список папки и навигация
│   │   ├── settings.ts         # что приложение помнит
│   │   ├── i18n.tsx            # язык интерфейса (RU/EN)
│   │   ├── skin.tsx            # скин и светлая/тёмная тема
│   │   └── strings.tsx         # весь текст интерфейса, оба языка
│   └── components/
│       ├── Stage.tsx           # зум и панорамирование одним transform
│       ├── Filmstrip.tsx       # миниатюры сбоку
│       ├── GridView.tsx        # вся папка сразу
│       ├── InfoPanel.tsx       # EXIF
│       ├── AssocCard.tsx       # переключатель приложения по умолчанию, с проверкой
│       └── SettingsScreen.tsx
└── src-tauri/
    └── src/
        ├── proto.rs            # протокол limg:// — байты идут мимо IPC
        ├── imageio.rs          # мост к ImageIO: декод, кодирование, метаданные
        ├── assoc.rs            # ассоциации файлов через LaunchServices
        ├── scan.rs             # список папки и натуральная сортировка
        ├── exif.rs             # метаданные для информационной панели
        └── fileops.rs          # корзина, перемещение, буфер обмена, конвертация
```

## Чего не будет

- **Только macOS.** ImageIO — это и есть весь смысл: благодаря ему работают RAW и PSD
  без единого вшитого декодера, а больше нигде его нет. Кроссплатформенная сборка была
  бы другой программой.
- **Никакой правки.** Это работа [lil edit](https://github.com/mitya-lsnk/lil-edit).
